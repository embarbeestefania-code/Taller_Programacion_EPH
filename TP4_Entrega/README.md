# TP4 - Clasificando informales en la EPH

Trabajo Práctico Nº 4 - Taller de Programación  
Universidad de Buenos Aires

## Objetivo
Predecir la informalidad laboral en 2025 utilizando información de la EPH 2024-2025 y comparar el desempeño de distintos modelos de clasificación.

## Modelos
- Regresión logística
- LASSO
- Ridge
- CART

## Metodología
Se utilizan datos longitudinales 2024-2025, validación cruzada de 5 folds y técnicas de regularización para comparar capacidad predictiva y selección de variables.
